# Инструкции для следующей сессии

- Сначала прочитайте `README.md`: там сборка, установка, возврат заводской оболочки и сведения о телевизоре.
- Перед изменениями проверьте `git status`. Не стирайте и не перезаписывайте незакоммиченные правки пользователя.
- `build/keys/red-panel.jks` — локальный ключ подписи. Не добавляйте его, APK или другие файлы из `build/` в Git. Для обновления установленного APK используйте тот же ключ.
- Это настоящий телевизор по ADB. Перед активными проверками HDMI учитывайте, что пользователь может играть на PS4; сначала используйте чтение журналов и состояния.
- Заводская оболочка `com.yandex.tv.home/.HomeActivity` должна оставаться доступной. Команда возврата есть в `README.md`.
